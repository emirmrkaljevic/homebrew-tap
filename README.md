# emirmrkaljevic/homebrew-tap

Homebrew formulae for my command-line tools.

```sh
brew install emirmrkaljevic/tap/behave
```

| Formula | What it does |
|---|---|
| [behave](https://github.com/emirmrkaljevic/behave) | Record how a CLI behaves, then prove a rewrite (Rust, Go, refactor) behaves the same. |

Each formula installs the prebuilt release binary for macOS or Linux (Intel and ARM).
